# Project Start Sequence

Follow this exact order to avoid creating a large empty microservice skeleton.

## Step 1

Create the monorepo and CI.

## Step 2

Create shared tooling packages.

## Step 3

Create Docker infrastructure only.

## Step 4

Create `auth-service` and `restaurant-service`.

## Step 5

Create one web client and one React Native client.

## Step 6

Implement login + branch selection + dashboard.

## Step 7

Add catalog.

## Step 8

Add inventory ledger.

## Step 9

Add order lifecycle.

## Step 10

Add kitchen display.

## Step 11

Add delivery state machine.

## Step 12

Add driver app.

## Step 13

Add tracking service + WebSocket.

## Step 14

Add notification consumers.

## Step 15

Add courier adapter abstraction.

## Step 16

Add reporting read models.

## Step 17

Add production hardening.

## Rule

At every step, keep the whole system executable. Never spend weeks building infrastructure before a user can complete a real business workflow.
